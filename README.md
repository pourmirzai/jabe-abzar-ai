## نحوه مشارکت

برای پیشنهاد ابزار جدید یک Pull Request باز کنید یا آن را در قالب زیر بفرستید:

```text
نام ابزار:
لینک:
دسته‌بندی پیشنهادی:
توضیح فارسی کوتاه:
```

- لینک ترجیحاً منبع رسمی ابزار باشد (وب‌سایت، GitHub یا داکیومنتیشن).
- موارد تکراری و اسپم رد می‌شوند.

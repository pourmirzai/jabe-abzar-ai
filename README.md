# جعبه‌ابزار هوش مصنوعی برای فارسی‌زبان‌ها

> هدف این مخزن: ثبت سریع، مرتب‌سازی و دسترسی آسان به ابزارهایی که برای ساخت محصول، توسعه نرم‌افزار، طراحی، اتوماسیون و کار با هوش مصنوعی مفید هستند.

## نحوه مشارکت

برای افزودن ابزار جدید می‌توانید یک Pull Request باز کنید یا ابزار را در قالب زیر ارسال کنید:

```text
نام ابزار:
لینک:
دسته‌بندی پیشنهادی:
توضیح فارسی کوتاه:
```

- لینک می‌تواند وب‌سایت، مخزن GitHub، صفحه داکیومنتیشن، صفحه مارکت‌پلیس یا هر منبع اصلی دیگر ابزار باشد.
- توضیح‌ها باید کوتاه و مبتنی بر واقعیت باشند.
- ابزارهای تکراری و لینک‌های بی‌کیفیت یا اسپم ممکن است رد شوند.
- لینک رسمی یا منبع اصلی ابزار ارجحیت دارد.

## اصول انتخاب ابزارها

- کاربردی بودن برای کاربران فارسی‌زبان
- داشتن لینک معتبر و ترجیحاً رسمی
- توضیح کوتاه، دقیق و بدون ادعای تأییدنشده
- پرهیز از ابزارهای تکراری، اسپم و لینک‌های نامعتبر
- امکان ثبت ابزارهای رایگان، متن‌باز، تجاری یا freemium
